# RQ4: Generation-backbone sensitivity

The two scripts in `main_pipeline/` are the fixed retrieval and verification
pipeline used after atoms and inversions are generated by a selected backbone.
For the reported comparison, the retrieval encoder remains
`BAAI/bge-base-en-v1.5`; only the atomization/inversion fields supplied to this
pipeline change.

The latest server project snapshot does not contain the standalone generation
launcher or saved per-backbone generated CSV files. Therefore this folder
preserves the available evaluation code but does not overstate end-to-end
reproducibility of Table 7.
